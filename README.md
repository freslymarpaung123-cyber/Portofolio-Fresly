# FRESLY.DEV — Portfolio

Website portfolio personal Fresly Gabriel Marpaung dengan gaya **Interactive Space Portfolio**. Dibuat menggunakan HTML, CSS, dan JavaScript murni tanpa framework atau proses build.

## Menjalankan website

1. Buka folder `fresly-portfolio` di Visual Studio Code.
2. Jalankan `index.html` menggunakan Live Server atau ekstensi server lokal lain.
3. Website juga dapat dibuka langsung melalui browser, meskipun menjalankannya melalui server lokal lebih disarankan.

## Fitur

- Opening / loading animation dengan progress.
- Background bintang bergerak menggunakan Canvas.
- Efek cahaya, shooting star, orbit, dan kartu profil melayang.
- Navbar kapsul dengan status menu aktif dan navigasi mobile.
- Animasi reveal saat halaman digulir.
- Kartu profil dengan efek tilt pada perangkat pointer.
- Filter proyek dan popup detail proyek.
- Kontrol gulir atas/bawah dan indikator progres halaman.
- Layout responsif untuk desktop, tablet, dan ponsel.
- Dukungan `prefers-reduced-motion` untuk pengguna yang mengurangi animasi.

## Hal yang perlu disesuaikan sebelum dipublikasikan

1. Ganti `EMAIL_KAMU@example.com` di `index.html` dengan alamat email aktif.
2. Tambahkan foto profil asli jika ingin mengganti monogram huruf F pada kartu profil dan bagian About.
3. Ganti mockup visual proyek dengan screenshot asli hasil pekerjaan setelah dokumentasi siap.
4. Pastikan rincian kontribusi untuk project bootcamp sesuai dengan bagian yang benar-benar dikerjakan.
5. Tambahkan tautan GitHub, LinkedIn, atau demo yang benar setelah tersedia.
